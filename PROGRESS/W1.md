**编码**
- `RedisServer`: Netty ServerBootstrap 监听 :6380，Boss(1) + Worker(1)
- `RespDecoder`（亲手）:
  - `+SimpleString`: bytesBefore('\n') → readCharSequence → skipBytes(2)
  - `$BulkString`: mark → bytesBefore → 读长度 → 检查内容是否完整 → reset 如需
  - `*Array`: mark → 读数量 → 循环调 decodeBulkString → reset 如需
  - 重构：抽 `decodeSimpleString` / `decodeBulkString` / `decodeArray` 三个方法
- `RespEncoder` 骨架已建，待填充
- 数据类：`RespSimpleString` / `RespBulkString` / `RespArray`

**单测**
- 8 个单测全绿：`+` 正常/半包/空 → `$` 正常/null/半包 → `*` ECHO/PING 命令

**卡壳→解决**
- `$` 半包测试 IndexOutOfBoundsException → 发现只检查了 `\r` 没检查 `\n`，改为 `bytesBefore('\n')` + mark/reset
- `$` 解析用错 `len`（长度行长度）当内容长度 → 引入 `contentLen` 变量
- `*` 数组 `Collections.singletonList` 多包一层 → 改用 `new RespArray(list)`
